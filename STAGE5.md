# Stage 5 — Conversation workspace improvements

- Added All / Favorites / Pinned conversation filters.
- Added a favorite toggle to each conversation action menu and star indicator.
- Added per-message copy buttons.
- Updated application viewport sizing to 100dvh for mobile browsers.
- Clarified the demo-only login status in Persian and English.

## Limitations
Authentication is a local demonstration, not secure production authentication. Attachments are metadata-only. Live AI requires separately configured backend credentials.

## Run
`npm install` then `npm run dev`. Run `npm run build` to validate locally.
